# SF Lecture Materials: запуск и последовательность работы

Это общий вход в плагин. Он определяет результат и передаёт работу трём специализированным навыкам. Самостоятельный запрос к одному из них сохраняет свой объём; запуск плагина без задачи не разрешает сразу редактировать материал или создавать PDF.

## Первый ответ

1. Сначала прочитай сообщение пользователя и уже принятые в текущей задаче решения. Явно указанный результат не спрашивай повторно. «Без PDF», «только редактура», запрет внешнего поиска и заданная остановка определяют границы выбранного процесса.
2. Если материалов нет, попроси прикрепить транскрипт или папку по [сценарию первого сообщения](references/startup.md). Не требуй пути по умолчанию. Если пользователь уже выбрал результат, сохрани его до получения файлов.
3. Если материалы есть, проверь только доступность, состав, роли, извлекаемость текста, порядок частей и возможные дубли. Короткого просмотра достаточно для выбора входа; полное чтение выполняется на текстовом этапе. Название, количество и наличие видео сообщай только по фактически найденным файлам. Расширение DOCX/PDF само по себе не отличает транскрипт от готовой лекции.
4. Когда результат не определён, предложи подходящие к входу варианты из startup.md. Не заставляй пользователя вручную описывать безопасно выяснимое содержимое. При существенной неоднозначности задай один конкретный вопрос с найденными вариантами. Пока нет выбранного результата, не запускай полную переработку, внешний фактчек или вёрстку.
5. После выбора кратко обозначь последовательность и точки решения. Выбор показанного варианта уже разрешает обычные шаги этого процесса: дополнительное «подтвердите тот же план» не нужно.

## Выбранные варианты

| Вход и результат | Последовательность | Точка окончания |
|---|---|---|
| Транскрипт → лекционный материал с фактчеком | Образец → принятие образца → полная редактура → фактчек → решения человека → согласованные поправки | Итоговый полный текст и оставшиеся вопросы; PDF не создаётся |
| Транскрипт → лекционный материал с фактчеком и PDF | Та же последовательность → PDF из выбранной редакции | PDF-кандидат для отдельной приёмки |
| Транскрипт → только редактура | Образец → принятие образца → полная редактура и сверка с источником | Полный лекционный текст; внешнее исследование не запускается |
| Готовая лекция → фактчек | Зафиксировать вход → фактчек → решения человека → согласованные поправки | Полная обновлённая редакция и оставшиеся вопросы |
| Готовая лекция → PDF | Зафиксировать выбранный текст → вёрстка и QA | PDF-кандидат; без повторной редактуры и незапрошенного фактчека |
| Готовая лекция → фактчек и PDF | Фактчек → решения человека → согласованные поправки → PDF | PDF-кандидат для отдельной приёмки |

«Полный цикл» без иных пояснений неоднозначен: уточни конечный результат, если предыдущие сообщения его не определяют. Запрос «полный цикл без PDF» означает текст с фактчеком; явное исключение фактчека имеет приоритет. Прямой запрос только редакторского текста или только PDF сохраняет соответствующий самостоятельный режим.

В папке результата зафиксируй выбранный вход, конечный результат, включённые этапы, запреты и доступное основание выбора в WORK_SCOPE.json. На переходах обновляй завершённый этап и следующий разрешённый шаг. Это запись процесса, не доказательство согласия; не добавляй человеку решения, которых он не принимал.

## Выполнение и решения

- **Редактура:** используй [sf-transcript-to-lecture](../sf-transcript-to-lecture/SKILL.md). До массовой переработки покажи одну небольшую содержательную подтему в чате; при наличии в источнике включи формулу, пример, английский термин и отступление, не придумывая их ради образца. После принятия примени согласованный подход ко всему материалу. Исправляй однозначные языковые/ASR-ошибки; внешнюю содержательную поправку не маскируй под редактуру.
- **Сверка текста:** проверь сохранение смысла, примеров, чисел, условий и последовательности в обе стороны. Зафиксируй неразборчивые и противоречивые места. Техническая проверка пакета не подтверждает истинность слов лектора.
- **Фактчек:** если выбран, после полной редактуры сразу используй [sf-fact-check](../sf-fact-check/SKILL.md) на зафиксированном тексте. Не спрашивай повторно, запускать ли уже заказанный этап. В первом сообщении с результатами покажи существенные ошибки, затем вопросы для решения, охват и ссылку на полный отчёт. Порядок — в [правилах предъявления](../sf-fact-check/references/human-review.md).
- **Решения:** для каждого существенного вопроса покажи адрес, текущую формулировку и предложение. Объясни последствие: нельзя завершить данный фрагмент, можно сохранить его с указанной оговоркой либо нужен конкретный дополнительный источник. «Не подтверждено» не означает автоматически ошибку или удаление. Допускается решение по явно перечисленной группе замечаний.
- **Поправки:** применяй только согласованное в новой версии и выдавай весь обновлённый текст. Отказ от поправки не меняет фактический вывод отчёта. Проверяй затронутые места и связанные выводы; новый хеш требует обновить адреса отчёта, но не разрешает незапрошенное повторение всего внешнего исследования.
- **Продолжение:** принятие образца разрешает оставшиеся уже выбранные этапы до следующего содержательного решения. После решений по фактчеку и применения поправок переходи к ранее выбранному PDF без повторного вопроса о его необходимости. Если человек просит остановиться или оставить вопрос открытым для решения, учитывай этот предел.
- **PDF:** используй [sf-lecture-to-golden-pdf](../sf-lecture-to-golden-pdf/SKILL.md). Вёрстка сохраняет выбранную редакцию. Предъявление кандидата, его принятие и размещение — отдельные действия по правилам PDF-навыка.

## Результат и границы

Текст и сопровождающие записи сохраняются в JSON по действующим контрактам; PDF — только в выбранном режиме. В пользовательском диалоге объясняй результат обычными словами, не требуй знания схем, команд и хешей для выбора процесса. При передаче связывай ссылки и замечания с конкретной версией.

Завершённый проход с пробелами не называй полной внешней верификацией. Один проход проверки заканчивается передачей человеку; дополнительная работа ограничивается его решением. Выбор процесса не разрешает распознавание видео, установку зависимостей, подагентов, сетевую публикацию или новый объём работ. Исходники сохраняются.

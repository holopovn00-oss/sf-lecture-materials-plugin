# Правила работы с принятым A4-профилем

Используйте предоставленный активный профиль A4 и закреплённый Golden Gate с учётом явно принятых уточнений. Профиль является единственным источником числовой геометрии; этот документ не вводит параллельную таблицу размеров. Если профиль или эталон недоступен, сообщите конкретное ограничение вместо предположения о соответствии.

Сохраняйте полный принятый текст и выбранные исходные визуалы. Число страниц определяется материалом. Переполнение разрешается допустимым переносом, без уменьшения шрифта, обрезки текста или изменения подписей. Самостоятельная тема и следующий визуальный блок начинают новую страницу. Название подтемы показывается только на её первой странице; продолжение сохраняет название раздела и служебные элементы без повторного крупного заголовка.

Последовательные абзацы внутри одного фрагмента идут общим потоком: левая колонка сверху вниз, затем правая. Граница абзаца не создаёт новую пару колонок. Новый таймкод или визуальный блок обозначает начало следующего отдельного фрагмента. Границы абзацев, фиксированные интервалы и точные привязки к исходному тексту сохраняются.

Карточка с изображением, подписью и имеющимся временем неделима. Заголовок и плашка связаны с началом содержания. Абзацы переносятся по принятому правилу, с сохранением порядка чтения. Содержание, номера и ссылки рассчитываются по итоговой вёрстке полного документа.

На первой странице каждого крупного раздела фон чистый: внутренний паттерн отсутствует по принятому A41. На последующих страницах того же раздела паттерн расположен под содержимым; наличие рисунка или начало новой подтемы этого правила не меняет. В Golden Gate страница 3 показывает начало раздела без паттерна, страницы 4–5 — последующие страницы с паттерном.

Декоративные паттерны технически извлекаются из существующего эталона. Содержательные изображения и схемы заново не генерируются. Формальный QA Python и визуальный просмотр всех страниц имеют отдельные основания; оба связаны с точной версией PDF. При поздней содержательной ошибке требуется решение пользователя о возврате.

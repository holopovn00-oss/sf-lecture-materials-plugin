# SF Lecture Materials 0.3.0

Архивные сведения об этом выпуске. Актуальный выпуск и действующие инструкции указаны в [индексе документации](README.md). Проверки ниже относятся только к названной версии.

## Изменение поведения

В плагине появился третий самостоятельный навык **sf-fact-check**. Он проверяет факты, определения, расчёты, гипотезы, теории, причинные объяснения и другие проверяемые утверждения по внешним доказательствам. Результат — отдельный JSON-отчёт и список замечаний в чате. Предложения изменяют текст только после решения человека.

Доказательная основа ограничена нормативами, официальной документацией, академическими публикациями, официальными данными и первичными документами, соответствующими утверждению. Для арифметики допустим воспроизводимый расчёт. Отсутствие подтверждения, спорность и устаревание различаются; гипотеза не объявляется установленным фактом из-за самого существования статьи.

Каждое замечание содержит точную цитату и её адрес, условия утверждения, источник с прочитанным местом, ход вывода, ограничения и предлагаемую редакцию/вопрос. Решение «оставить» сохраняется отдельно от вывода проверки.

## Совместимость

- Добавлен FactCheck **1.0.0**; существующие форматы LectureText **3.0.0**, text-review **2.0**, candidate-manifest **2.0** и профиль A4 **2.1.0** сохранены.
- Сохранена проверка исторических текстовых/PDF-пакетов.
- Фактчекинг включается по запросу; обычная редактура и вёрстка не запускают внешнее исследование автоматически.
- Принятые FC-замечания передаются в существующие редакторские решения. Исходный транскрипт и его provenance сохраняются.
- Новых обязательных Python-библиотек, платных интеграций и MCP-серверов нет.

## Проверка выпуска

Финальный gate включает полный unittest-набор с настоящим Tectonic и нулём пропусков, целостность 18 закреплённых PDF-ресурсов, manifest плагина, три SKILL.md, относительные ссылки документации и целостность контрольного отчёта.

Проверено 12 сентября 2026: **89 тестов прошли без ошибок и пропусков**; 18 ресурсов, manifest, три навыка и 54 относительные ссылки прошли проверки. Полный набор выполнен один раз на финальном gate. Исходные файлы контрольного текста не изменены.

Контрольный текст содержит семь утверждений: неверный расчёт, неверное описание Python round, неверную интерпретацию p-value, ошибочное число в определении секунды SI, явное допущение модели, неподтверждённую гипотезу и намеренно ложный учебный пример. Внешние основания действительно прочитаны; выводы рассмотрены текущим исполнителем. Независимое ревью и пользовательское принятие не симулируются.

Сведения о машинной проверке: [validation-0.3.0.json](validation-0.3.0.json). Тестовые пользовательские ответы в unit-тестах являются только синтетическими fixtures.

## Границы стабильности

Версия фиксирует указанные интерфейсы и проверенный объём поведения. Статус FACT_CHECK_RECORD_VALIDATED означает структурную целостность записи, точность цитат/хешей и пересчёт поддерживаемой арифметики. Он не удостоверяет истинность внешнего утверждения, подлинность/качество публикации, независимость доказательств, полноту выделения фактов или реальное согласие человека.

Задачи любой дисциплины всё равно требуют предметной проверки и человеческого решения. Полный научный консенсус не определяется голосованием ссылок. Для недоступных источников и недостаточных условий сохраняются пробелы.

Установленные плагины на пользовательских машинах автоматически не обновляются. Полная проверка установки/обновления на каждой поддерживаемой ОС не проводилась; инструкция опирается на фактический CLI 0.153.4, чтение установки и официальный код управления marketplaces. Универсальный рендерер произвольной лекции в эту версию не добавлен; прежние ограничения PDF сохраняются.

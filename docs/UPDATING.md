# Подключение SF Lecture Materials 0.1.0

Текущая редакция находится в main этого репозитория. Для воспроизводимой установки фиксируйте полный SHA нужного коммита и проверяйте manifest плагина в нем.

В Codex откройте каталог плагинов и подключите репозиторий holopovn00-oss/sf-lecture-materials-plugin как marketplace, затем выберите SF Lecture Materials. Для CLI используйте команды, доступные в установленной версии: codex plugin marketplace --help и codex plugin --help. Репозиторий содержит .agents/plugins/marketplace.json с именем sf-lecture-materials и путь ./plugins/sf-lecture-materials.

Обновление GitHub не переустанавливает локальный плагин автоматически. Обновление marketplace, переустановка, очистка кеша и изменения локальных конфигураций выполняются только по отдельному запросу. После разрешенного обновления проверьте фактическую версию 0.1.0 в установленном .codex-plugin/plugin.json и откройте новую задачу; старая задача может сохранять прежние инструкции.

После обновления откройте новую задачу. Полный цикл проверяет PDF-среду заранее, но не блокирует текстовые этапы отсутствующими PDF-зависимостями. Перед PDF нужен READY; без формул используется --no-math. Установка пакетов, Tectonic и TeX-кэша требует разрешения. Зависимости находятся внутри plugins/sf-lecture-materials: requirements.txt и runtime-requirements.json. Python-пакеты устанавливаются в managed venv; дальнейшие команды запускаются через python.interpreter из отчета. Версия плагина остается 0.1.0; схемы и библиотеки имеют собственные версии. Технические проверки не заменяют визуальный просмотр и приемку.

Для отката выбирайте проверенный предыдущий коммит. История Git не удаляется при очистке текущего дерева.

# SF Lecture Materials 0.4.0

Архивные сведения об этом выпуске. Актуальный выпуск и действующие инструкции указаны в [индексе документации](README.md). Проверки ниже относятся только к названной версии.

Версия добавляет общий вход в плагин и согласованную последовательность работы с лекцией. При запуске без файлов плагин просит добавить материалы; после их получения предлагает результат с учётом вида входа. Ранее выбранный режим и принятые решения сохраняются при переходах между этапами.

## Изменения

- Новый `sf-lecture-materials` принимает материалы и направляет работу к трём специализированным навыкам. В manifest обновлён стартовый запрос.
- Для транскрипта предлагаются текст с фактчеком, текст с фактчеком и PDF либо только редактура. Для готовой лекции — фактчек, PDF либо оба этапа без автоматической переработки готового текста.
- Образец редактуры предъявляется до обработки всей лекции. После его принятия уже выбранный фактчек не требует повторного разрешения на тот же этап.
- Первый результат фактчека начинается с существенных ошибок и вопросов для решения. Повторы объединяются с сохранением всех FC-ID и исходных адресов. Полный JSON содержит остальные уточнения и подтверждения.
- После решений человека согласованные поправки сохраняются в новой полной редакции. Уже выбранный PDF получает эту редакцию; отдельная приёмка PDF-кандидата сохраняется.
- Обновлены пользовательская инструкция, установка четырёх навыков и откат на 0.3.0. Описано сохранение конфликтующего самостоятельного DOCX-навыка вне активного каталога.

Форматы LectureText 3.0.0, FactCheck 1.0.0, text-review 2.0, manifest 2.0, профиль A4 2.1.0, Python-компоненты и закреплённые ресурсы не изменены. Миграции существующих документов нет.

## Проверка сценариев текущим исполнителем

Это содержательное сопоставление инструкций с согласованным процессом. Оно не является запуском модели в новой задаче и не заменяет проверку фактического диалога.

| Ситуация | Предусмотренное действие | Основание |
|---|---|---|
| Плагин без файлов | Попросить прикрепить материалы; путь не обязателен | Общий вход, первый ответ 2; startup.md |
| Транскрипт без выбранного результата | Краткая опись и три подходящих варианта | Первый ответ 3–4; startup.md |
| Результат указан заранее | Сохранить выбор, перейти к следующему этапу | Первый ответ 1 и 5 |
| Готовая лекция | Фактчек/PDF/оба этапа без обязательной повторной редактуры | Таблица вариантов; startup.md |
| Только редактура | Завершить текстом, без внешнего исследования | Таблица вариантов; текстовый навык |
| Только PDF готового текста | Сохранить выбранный текст, выполнить PDF | Таблица вариантов; PDF-навык |
| Образец ещё не принят | Показать образец до массовой переработки | Текстовый навык, подготовка 3 |
| Образец принят, фактчек выбран | Закончить редактуру и выполнить фактчек | Выполнение: продолжение; текстовый навык |
| Много фактологических записей | Выделить существенное, объединить повторы, дать полный JSON | human-review.md |
| Важный тезис не подтверждён | Отделить доказательный статус от влияния; предъявить вопрос | human-review.md, приоритет |
| Поправки согласованы, PDF выбран | Новая редакция, проверка затронутого, переход к PDF | Выполнение: поправки/продолжение |
| Пользователь останавливает работу | Учесть остановку, не продолжать выбранный процесс | Выполнение: продолжение |

## Техническая проверка и пределы

Результаты финального локального запуска и хеши файлов — в [validation-0.4.0.json](validation-0.4.0.json). Полный набор тестов должен пройти без пропусков, включая фактическую компиляцию LaTeX. Дополнительно проверяются четыре SKILL.md, manifest, имя marketplace, 18 закреплённых ресурсов и локальные ссылки документации.

Плагин остаётся набором инструкций, ресурсов и проверочных компонентов. Маршрутизация и точки решения заданы инструкциями; отдельный программный движок состояний не добавлен. Валидаторы проверяют структуру и записанные данные, но не гарантируют поведение модели, смысловую полноту, научную истинность или подлинность согласия пользователя. Независимое ревью и новая полная обработка лекции в этот выпуск не входили.

После локального обновления новую версию следует открыть в новой задаче Codex: уже открытая задача могла сохранить прежние инструкции. Факт установки и совпадение файлов проверяются отдельно от фактического диалога.

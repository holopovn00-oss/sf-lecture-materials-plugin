# SF Lecture Materials 0.4.1

Исправлены метаданные ресурсов и текущие указатели документации. В выпуске 0.4.0 manifest плагина уже содержал новый номер, а поле plugin_version в manifest ресурсов оставалось 0.3.0. В 0.4.1 эти значения согласованы; регрессионный тест сверяет их непосредственно между файлами.

- README и инструкция установки указывают 0.4.1. Откат ведёт к фиксированному тегу 0.4.0.
- Добавлен [индекс документации](README.md) с текущими инструкциями, версиями форматов и историческими отчётами.
- Заметки предыдущих выпусков явно помечены как архивные; их проверочные отчёты сохранены без изменения.
- Уточнены ссылки на происхождение сторонних ресурсов.

Сценарий запуска, редактура, фактчек, PDF-компоненты, форматы документов и содержимое 18 закреплённых ресурсов сохраняют поведение 0.4.0. Marketplace, диапазоны зависимостей и правила Git проверены на применимость к текущей поставке. Номер исходного ресурса или сообщение старого коммита не являются номером установленного плагина.

Результаты финального полного набора тестов, проверки четырёх навыков, manifest, ресурсов и ссылок находятся в [validation-0.4.1.json](validation-0.4.1.json). Сверка установленного плагина с опубликованными файлами выполняется отдельно после обновления. Фактический диалог модели в новой задаче не входит в эту проверку.

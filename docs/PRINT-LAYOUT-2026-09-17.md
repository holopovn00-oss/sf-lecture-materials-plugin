# Печатная верстка: ревизия 2026-09-17

Изменения main к опубликованной версии 0.4.1. Отдельный релиз и обновление установленного кеша этим изменением не выполняются.

## Согласованные правила

- На обложке нет порядкового номера урока. Смысловые числа сохраняются. Помощник `cover_title` требует явно подтвержденный ordinal; исходный заголовок хранится отдельно.
- Основной текст: две колонки, красная строка 5 мм, дополнительный интервал между обычными абзацами 0 мм. Продолжение абзаца не получает новый отступ. Обычный кегль и интерлиньяж сохранены; отдельные формулы сохраняют зазор 4 мм.
- Подтемы одного крупного раздела образуют непрерывный поток, с измеренными заголовками. Нет принудительного разрыва страницы по topic_id. Между крупными разделами сохраняется прежняя граница.
- Авторская проза нормализуется до фиксации текста: е вместо ё, тире – вместо —. Точные цитаты, подтвержденные имена, неоднозначные смысловые случаи, формулы, код и технические строки защищаются адресными исключениями. Автоматического удаления декоративных символов по внешнему виду нет.

## Интерфейс и совместимость

Формат LectureText остается 3.0.0. Профиль A4 2.1.0 получил `layout_revision=2026-09-17` и новый SHA-256; старые кандидаты должны ссылаться на сохраненный профиль своей версии. Нельзя заменять файл в их manifests и переносить прежний PASS.

`build_units(lecture, topic_ids, assets, profile, skill_root)` принимает список подтем одного крупного раздела в структуре лекции; порядок берется из placements, не из списка фильтра. `None` выбирает весь вход, только если в нем один крупный раздел. Вызов с отдельной строкой topic_id оставлен для существующих локальных рендереров с внешним заголовком. Для нового компактного потока вызывайте paginate на общей последовательности, а не отдельно по теме.

В render-plan служебный текст заголовка имеет `topic_heading_for`; первая строка темы в flow имеет `topic_heading=true`. Валидатор проверяет текст, размер и координаты заголовка, фактические отступы, межабзацные интервалы и общую пару колонок. В column_pairs вместо одиночного topic_id возвращается список topic_ids.

`text_typography.normalize_prose` вызывается явно на просмотренной прозе до фиксации пакета, возвращает журнал адресных замен и не изменяет входные данные. Это не классификатор цитат, имен или машинного происхождения текста. PDF-верстка не запускает его автоматически.

## Проверки и границы

Проверка этой ревизии: `python -m unittest discover -s tests -v` с заданными SF_TECTONIC и заранее заполненным SF_TECTONIC_CACHE – 96 тестов, OK, без пропусков. verify_bundle.py – RESOURCES_VERIFIED, 18 файлов. Оба измененных навыка прошли quick_validate.py в режиме Python UTF-8; git diff --check без замечаний. Это локальная проверка текущим агентом, не независимое ревью.

Регрессии: сохранение смысловых чисел на обложке; адресные исключения типографики; геометрия красной строки и нулевого интервала; непрерывное размещение подтем с видимыми заголовками; отказ при неправильном отступе; прежние реальные TeX/PDF-проверки формул, глифов, дробных черт и переносов.

Ресурсы закреплены обновленными SHA-256 в bundle-manifest. Это не означает приемку какой-либо лекции. Обложка, содержание, карточки, навигация и полный визуальный просмотр остаются частью выпуска конкретного PDF. Интеграционные PDF из тестов не заменяют заказанный полный документ.

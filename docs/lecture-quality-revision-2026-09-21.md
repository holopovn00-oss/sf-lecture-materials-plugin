# Спецификация изменений SF Lecture Materials

Историческая запись от 21 сентября. Уточнения источников, подписей и авторских схем из [редакции 22 сентября](lecture-quality-revision-2026-09-22.md) имеют приоритет; упоминание извлечения из готового конспекта ниже не является действующим разрешением.

Область: только плагин `sf-lecture-materials`. Согласована пользователем 21 сентября 2026 года после сравнения редакций лекции и просмотра исправленного кандидата. Это разрешение обновить плагин и спецификацию; оно не подменяет отдельную приемку PDF.

## Наблюдения при сравнении

- Редакция с большим числом исходных слайдов лучше передавала промежуточные действия преподавателя. Чистые слайды теряли полезные пометки.
- В короткой редакции мелкие заголовки дробили единую мысль, а жесткие границы разделов оставляли страницы с короткими окончаниями.
- Для повторения расчетов нужны пояснения показателей степени, даты промежуточной оценки, параметров калькулятора и округления последнего платежа.
- Ошибки в исходной рукописной формуле нельзя возвращать в текст вместе с восстановленным изображением. Правильная формула и подпись должны явно отличаться от исходной ошибочной записи.
- Количество иллюстраций само по себе не гарантирует учебную пользу. Увеличенный фрагмент должен решать проблему читаемости.

## Изменения

1. Подключить [AGENTS.md плагина](../plugins/sf-lecture-materials/AGENTS.md) из всех четырех навыков. Область действия явно ограничена этим плагином; общие инструкции репозитория не изменяются.
2. Закрепить [правила композиции и пояснений](../plugins/sf-lecture-materials/references/lecture-quality.md). Локальные предпочтения хранятся в необязательном `LOCAL_MEMORY.md` рядом с AGENTS.md, исключенном из Git; это не глобальная память аккаунта.
3. Форматировать время только на этапе отображения; не менять исходные миллисекунды. Объединять интервалы по реальному `source_uri`, соседству блоков и порядку дат, без предположений о префиксах ID.
4. Исправить поиск переноса: после слишком широкого варианта с дефисом продолжать проверку последующих границ, потому что целое слово без дефиса может поместиться. Предпочитать компактный допустимый абзац при прежних пределах пробелов.
5. Убирать паттерн на первой странице каждого раздела, а не только первой странице основного текста.
6. Добавить необязательную ширину конкретного визуала с обоснованием. Максимальные размеры профиля и пропорции остаются обязательными; конкретный ID кредитного слайда не зашивается в код.
7. Проверить регрессии на переносах, таймкодах, разных источниках, началах разделов и пределах размера карточки. Выполнить проверки пакета и регрессионную сборку лекции.

## Критерии результата

Сохраняются исходные тексты, формулы и точные привязки; содержательные добавления проверяются до верстки. Технические проверки не заменяют просмотр всех страниц. Сокращение почти пустых страниц не достигается удалением условий или уменьшением нормативного шрифта. Golden PDF и его визуальные токены не меняются.

В контрольной редакции лекции объединение связанных тем сократило объем с 23 до 20 страниц при сохранении прежнего текста и 48 формул; добавлены шесть объясняющих абзацев и вводная схема. Это результат конкретной лекции, а не норматив количества страниц, формул или изображений.

## Дополнение по источникам

Перед локальным таймкодом показывается «Видео N». Явная карта time_sources связывает метку с source_uri и основанием; длительности записей не складываются. Подписи изображений идут в порядке «Источник → Слайд № → Тема», с дополнительной страницей PDF при извлечении из конспекта. Для авторской схемы номер исходного слайда не выдумывается. Многострочная подпись сохраняет заданные смысловые строки.

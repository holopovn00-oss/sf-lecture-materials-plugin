# SF Lecture Materials

Плагин Codex для SF Education: полный учебно-методический текст из транскрипта в **JSON**, проверка фактов по внешним доказательствам и A4 PDF с сохранением смысловых абзацев и формул LaTeX.

Опубликованная версия: **0.4.1**. В `main` дополнительно реализована [ревизия печатной верстки 2026-09-17](docs/PRINT-LAYOUT-2026-09-17.md); она еще не является отдельным тегированным релизом. Общий вход и три специализированных навыка, локальные Python-проверки и помощники измерения/компиляции. SF Lecture Publisher и MCP-сервер не требуются.

| Навык | Вход | Результат |
|---|---|---|
| sf-lecture-materials | Запуск плагина, запрос и добавленные материалы | Выбор результата и переходы между этапами с сохранением решений |
| sf-transcript-to-lecture | Полный транскрипт и исходные привязки | lecture-text.json со смысловыми абзацами и LaTeX; происхождение и редакторский отчёт также в JSON |
| sf-fact-check | Текст или lecture-text.json | Отдельный fact-check.json: доказательства, замечания и решения человека |
| sf-lecture-to-golden-pdf | Проверенный текст и предоставленные материалы | A4 PDF, композиция, план размещения и проверки |

## Использование

Выберите плагин **SF Lecture Materials** и перетащите в чат транскрипт или папку. Если материалов ещё нет, плагин попросит добавить их. После краткой проверки состава он предложит подходящий результат, если вы ещё не указали его:

1. **Лекционный материал с фактчеком** — редактура, внешняя проверка и итоговый текст после ваших решений.
2. **Лекционный материал с фактчеком и PDF** — те же этапы, затем PDF из выбранной редакции.
3. **Только редактура транскрипта** — полный учебный текст без внешней проверки.

Для готовой лекции доступны фактчек, PDF или оба этапа; полная редактура не начинается автоматически. Явный выбор в вашем сообщении имеет приоритет: повторно отвечать на ту же анкету не требуется.

> Подготовь полный учебно-методический текст этой лекции только в JSON. Сохрани объяснения, примеры, условия и оговорки; оформи смысловые абзацы и формулы LaTeX.

> Собери PDF из этого проверенного JSON по SF Education, сохрани абзацы, формулы и полное содержание.

> Проверь факты, гипотезы и выводы в этом тексте по нормативам, документации и академическим работам. Выдай отдельный список замечаний с источниками и предложениями. Дождись моих решений перед исправлением.

Перед обработкой всей лекции плагин показывает один образец редактуры. После принятия образца он выполняет уже выбранные этапы до следующего содержательного решения. Если PDF выбран заранее, после решений по фактчеку и внесения поправок плагин переходит к вёрстке без повторного вопроса о необходимости PDF.

Первый результат фактчека содержит существенные ошибки, вопросы для решения, охват и ссылку на полный отчёт. Повторы объединяются с сохранением всех адресов; важные замечания не скрываются ради фиксированного числа пунктов. Решения можно задавать как «FC-ID — исправить / оставить / перепроверить» или по явно перечисленной группе.

Фактчекинг запускается по запросу или в выбранном варианте процесса и может выполняться перед PDF. Он проверяет истинность/обоснованность утверждений за пределами транскрипта; редактура проверяет сохранение исходного смысла. Вывод проверки и решение человека хранятся отдельно: «оставить» не превращает ошибку в подтверждённый факт.

Текстовый этап не создаёт DOCX и Markdown. Они допустимы как исходные форматы. Сначала завершается редактура, затем вёрстка сохраняет проверенную версию. Перед массовой переработкой согласуется один образец.

## Правила и форматы

- Полное учебное содержание сохраняется без сокращения до заданного объёма. Несодержательные связки/отступления и тавтология удаляются с учётом их функции.
- Каждый смысловой абзац хранится в content. Основная формула — display_math; короткое обозначение — math внутри runs. Исходный LaTeX остаётся в JSON.
- Исходные файлы имеют SHA-256, блоки — устойчивые ID и реальные locators. Для удаления части блока нужны точная цитата и символьный диапазон.
- PDF использует Inter для текста и встроенные TeX-шрифты для проверенных формул. Колонки балансируются по измеренной высоте с учётом абзацев, формул и висячих строк.
- Техническая проверка, содержательная сверка, просмотр каждой страницы, принятие образца и размещение файлов — отдельные результаты.

Текущие версии: FactCheck 1.0.0, LectureText 3.0.0, text-review 2.0, candidate-manifest 2.0, профиль A4 2.1.0. Проверка исторических LectureText 2.0.0 и manifest 1.0 сохранена; новые документы не мигрируют старые пакеты автоматически.

## Подключение

Репозиторий содержит marketplace .agents/plugins/marketplace.json и плагин plugins/sf-lecture-materials. [Инструкция обновления локальных машин](docs/UPDATING.md) описывает закреплённую версию v0.4.1, обновление из main, проверку установленной версии, зависимости и откат. Команды сверены с Codex CLI 0.153.4; минимальная совместимая версия CLI не установлена.

Для новой установки фиксированной версии:

~~~powershell
codex plugin marketplace add holopovn00-oss/sf-lecture-materials-plugin --ref v0.4.1
codex plugin add sf-lecture-materials@sf-lecture-materials
~~~

Если marketplace уже подключён к другой ветке/версии, сначала используй соответствующий раздел инструкции. После установки открой новую задачу Codex. Исторические открытые задачи не служат проверкой загрузки обновлённых инструкций.

## Зависимости и проверки

Python 3.11+. Текстовые и фактологические проверки используют стандартную библиотеку. Внешний фактчекинг требует доступного поиска и чтения первоисточников в Codex; платный коннектор или MCP-сервер не обязательны. Без доступа явно записываются пробелы. PyMuPDF, Pillow и ReportLab перечислены в requirements.txt. Для фактического LaTeX нужен Tectonic: доступный исполняемый файл или путь из окружения Codex; полная установка TeX не требуется. Для просмотра страниц нужен Poppler (pdftoppm).

Tectonic работает в untrusted mode; по умолчанию использует только указанный локальный кэш. --allow-downloads явно разрешает его пополнение. Инструкция и команда — в проверках PDF. Отсутствующий движок, шрифт или нечитаемая формула дают конкретный блокер, а не успешную заглушку.

Из корня репозитория:

~~~powershell
python -m pip install -r requirements.txt
$env:SF_TECTONIC = 'C:/Tools/tectonic.exe'
$env:SF_TECTONIC_CACHE = 'C:/Task/tectonic-cache'
python -m unittest discover -s tests -v
python plugins/sf-lecture-materials/skills/sf-lecture-to-golden-pdf/scripts/verify_bundle.py
~~~

Кэш должен быть заранее заполнен нужными TeX-ресурсами. Без Tectonic математические интеграционные тесты явно пропускаются; такой запуск не является полной проверкой релиза. Для релиза требуется ноль пропусков.

Набор покрывает текущий и исторический JSON, удаления с цитатой, хеши и решения, реальные inline/display-формулы, пропавшую формулу и черту дроби, несовпадение LaTeX с asset, интервалы и баланс колонок, перенос между страницами, шрифты, изображения и внутренние ссылки.

Для фактологического отчёта:

~~~powershell
python plugins/sf-lecture-materials/skills/sf-fact-check/scripts/verify_fact_check.py --report C:/Task/fact-check.json
~~~

Проверка только читает файлы, сверяет хеши/цитаты/состояния, допустимые категории источников и воспроизводит записанную числовую арифметику. Она не удостоверяет научную истинность, подлинность источника, независимость исследований или реальность согласия пользователя.

## Проверенный объём и ограничения

Плагин поставляет инструкции, ресурсы, валидаторы и компоненты компиляции/размещения основного текста. Универсального рендерера всей произвольной лекции нет: для конкретного материала Codex создаёт локальный скрипт обложки, содержания, карточек и навигации.

Компиляция доказывает воспроизводимость записанного LaTeX, а не его соответствие рукописному источнику. Проверка PDF измеряет фактические глифы и штрихи формулы; все коллизии компонентов, математическую верность и полное соответствие Golden она не сертифицирует. Отчёты не удостоверяют сами себя и не подменяют пользовательское принятие.

Контрольные примеры и тесты не являются принятием конкретной лекции. Перед массовой обработкой предъявляется и принимается образец. Стабильная версия фиксирует интерфейсы и проверенный объём; она не гарантирует отсутствие ошибок в любой дисциплине. Изменения и критерии выпуска описаны в [заметках версии 0.4.1](docs/RELEASE-0.4.1.md).

Карта актуальных документов, компонентов и исторических версий — в [индексе документации](docs/README.md).

## Ресурсы

Golden PDF, Inter и фирменные изображения находятся внутри PDF-навыка. verify_bundle.py проверяет **18** закреплённых ресурсов, включая новый профиль/контракт 2.1.0 и сохранённые исторические версии. Исходные хеши не переписаны. Происхождение записано в references/provenance.json; исторические пути не являются зависимостями исполнения.

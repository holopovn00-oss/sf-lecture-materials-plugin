# SF Lecture Materials

Плагин Codex для SF Education. Он превращает русскоязычный транскрипт в полный учебный текст JSON, проверяет отдельные утверждения по внешним источникам и собирает из принятой редакции A4 PDF со смысловыми абзацами и формулами LaTeX.

Текущая версия плагина: **0.1.0**.

## Что можно получить

| Навык | Вход | Результат |
|---|---|---|
| `sf-lecture-materials` | Добавленные материалы и запрос | Выбор нужного сценария и сохранение решений между этапами |
| `sf-transcript-to-lecture` | Полный транскрипт и исходные привязки | `lecture-text.json` с учебным текстом, LaTeX и редакторским отчётом |
| `sf-fact-check` | Текст или `lecture-text.json` | Отдельный `fact-check.json` с доказательствами и решениями человека |
| `sf-lecture-to-golden-pdf` | Проверенный текст и материалы | A4 PDF, план размещения и технические проверки |

## Как начать работу с лекцией

1. Выберите плагин **SF Lecture Materials** и добавьте транскрипт или папку с материалами
2. Укажите нужный результат:
   - учебный текст в JSON
   - учебный текст с фактчеком
   - учебный текст с фактчеком и PDF
3. Для готового текста укажите фактчек, PDF или оба этапа

Явно выбранный результат имеет приоритет. Плагин не начинает полную редактуру без такого выбора.

## Что требует вашего решения

Перед обработкой всей лекции примите один образец редактуры. После этого плагин выполняет согласованные этапы до следующего содержательного решения.

Фактчек создает отдельный отчет. Выберите исправление, сохранение или повторную проверку для адресных пунктов, например `FC-ID: исправить`. Решение «оставить» не подтверждает исходное утверждение.

PDF создается только из выбранной редакции. Автоматические проверки оценивают структуру, ресурсы и механику PDF. Они не заменяют содержательную сверку, просмотр страниц и ручную приемку.

## Подключение и проверка

Устанавливайте текущую версию из ветки `main`. Для воспроизводимой установки закрепляйте SHA коммита. Порядок подключения и обновления описан в [инструкции по обновлению](docs/UPDATING.md).

Для локальной структурной проверки из корня репозитория выполните:

~~~powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
~~~

Для изменений PDF-контура используйте [GitHub-gates](docs/GITHUB_GOVERNANCE.md). Полный PDF-релиз требует отдельной визуальной и ручной проверки.

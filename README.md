# SF Lecture Materials

Плагин Codex для подготовки материалов SF Education: из транскрипта — полный отредактированный лекционный текст, из готового текста — A4 PDF по закреплённому эталону оформления.

Версия: **0.1.0**. Плагин содержит два самостоятельных навыка и локальные Python-проверки. MCP-сервер и установка SF Lecture Publisher не требуются.

## Навыки

| Навык | Вход | Результат |
|---|---|---|
| `sf-transcript-to-lecture` | Транскрипт и доступные исходные привязки | Полный лекционный текст в JSON и Markdown, учёт исходных фрагментов и отчёт о редактуре |
| `sf-lecture-to-golden-pdf` | Готовый лекционный текст и предоставленные визуальные материалы | A4 PDF, композиция, план размещения, проверки и постраничный визуальный отчёт |

Основные правила:

- Сохранять полный смысл, слова и порядок подготовленного текста; не сокращать материал ради числа страниц.
- Внутри подтемы размещать сплошной текст без абзацных промежутков и отступов.
- Равномерно распределять текст между двумя колонками, включая последнюю страницу подтемы. Для обычного текста разница не более одной строки; нечётная дополнительная строка остаётся слева.
- Сохранять кегль, интерлиньяж, пропорции изображений и отдельные исходные таймкоды.
- Проверять фактический PDF, а затем отдельно просматривать каждую страницу.
- Предъявлять результат пользователю. Техническая проверка не заменяет его принятие и не разрешает публикацию материалов.

## Подключение в Codex

Для Codex CLI с поддержкой плагинов:

```powershell
codex plugin marketplace add holopovn00-oss/sf-lecture-materials-plugin --ref main
codex plugin add sf-lecture-materials@sf-lecture-materials
```

После установки начните новую задачу Codex, чтобы загрузились навыки. Команды сверены с интерфейсом Codex CLI 0.153.4. В составе репозитория находятся marketplace `.agents/plugins/marketplace.json` и плагин `plugins/sf-lecture-materials`.

Примеры запросов:

> Подготовь полный лекционный текст из транскрипта в указанной папке. Сохрани смысл и исходные привязки, покажи текст и редакторские замечания.

> Собери PDF из этого принятого лекционного текста. Используй предоставленные изображения, сохрани весь текст и равномерно распредели его между двумя колонками.

## Локальные зависимости

Нужен Python 3.11 или новее. Подготовка и проверка текстового пакета используют стандартную библиотеку. Проверка PDF требует PyMuPDF и Pillow; для программной вёрстки и тестов используется ReportLab. Навыки сначала используют доступные библиотеки, в том числе зависимости Codex.

При самостоятельной подготовке окружения:

```powershell
python -m pip install -r requirements.txt
```

Для растрового просмотра страниц нужен доступный Poppler (`pdftoppm`), например из среды Codex. Отсутствие визуального просмотра нельзя заменять успешным извлечением текста.

## Проверки

Из корня репозитория:

```powershell
python -m unittest discover -s tests -v
python plugins/sf-lecture-materials/skills/sf-lecture-to-golden-pdf/scripts/verify_bundle.py
```

Набор включает **39 тестов**: учёт полного текста, сохранение редакторских решений, целостность эталонных ресурсов, текст и навигацию PDF, а также балансировку фактических колонок. Отдельно проверяются неравные колонки, пустая правая колонка, растянутый интерлиньяж, смещённое начало и неверные метки в плане.

Проверка конкретного PDF выполняется по его manifest:

```powershell
python plugins/sf-lecture-materials/skills/sf-lecture-to-golden-pdf/scripts/verify_candidate.py --manifest path/to/candidate-manifest.json
```

Форматы входов и отчётов описаны в [текстовом навыке](plugins/sf-lecture-materials/skills/sf-transcript-to-lecture/references/package-checks.md) и [проверках PDF](plugins/sf-lecture-materials/skills/sf-lecture-to-golden-pdf/references/automated-checks.md).

## Проверенный объём и ограничения

Принятый пилот — одна короткая лекция, четыре страницы PDF. В первой подтеме получено 16/15 строк, во второй — 25/25; все страницы просмотрены. Основной текст и выбранные визуальные материалы сохранены. Транскрипт, видео и история пилота не входят в публичный пакет.

Плагин содержит инструкции, ресурсы и проверки; универсальный готовый рендерер произвольной лекции в него не включён. Codex создаёт или адаптирует локальный скрипт вёрстки для конкретного материала. Проверка колонок рассчитана на обычный горизонтальный текст; сложные формулы с несколькими базовыми линиями и особая компоновка требуют отдельного рассмотрения и не получают автоматический PASS. Проверки не сертифицируют смысл, полное соответствие Golden Gate или пользовательское принятие.

## Ресурсы

Эталонный PDF, A4-профиль, контракты, фирменные изображения и Inter находятся внутри PDF-навыка. Хеши 16 закреплённых ресурсов проверяет `verify_bundle.py`. Историческое происхождение записано в `references/provenance.json`; пути в нём относительны к исходной установке SF Lecture Publisher и не являются зависимостями исполнения.

Уточнения пользователя о сплошном тексте и балансировке имеют указанный в [Golden-правилах](plugins/sf-lecture-materials/skills/sf-lecture-to-golden-pdf/references/golden-rules.md) приоритет над прежними параметрами абзацев в закреплённых JSON.

Сведения о сторонних ресурсах — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
